# How To Apply OnlineFix

This one is really easy bro

**Step 1**: Go to Fixes and look for your game.

**Step 2**: Click on 'Fix'.

:::warning False Positives
Windows Defender may tell you that you have a trojan with a weird name, this is a false positive. All fixes are sourced directly from the onlinefix website. If this happens to you, Add Windows Defender exclusions to these folders:
1) Your Steam's Install Location (Usually in C:\Program Files (x86)\Steam)
2) Your AppData folder (C:/Users/YOURUSERNAME/AppData)

Alternatively, you could disable your antivirus as shown in the video.
:::
