# BetterSteamTools

BetterSteamTools is the piece that does the actual work in unlocking games.

It's based on [OpenSteamTool](https://github.com/OpenSteam001/OpenSteamTool) by OpenSteam001.

You can find the repo here: https://github.com/madoiscool/bettersteamtools

## You don't need to install it separately

The App handles it for you. You can manage it there. 
Get the app from: https://lua.tools/app.
